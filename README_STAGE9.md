# CloudVision AI — этап 9: проверка разметки перед обучением

Рабочая версия программы сортировки уже проверена на трёх JPEG; теперь нужны корректные ручные маски для обучения/проверки качества, особенно сильно облачные снимки. Этот этап не запускает нейросеть и не удаляет файлы.

## Установка на Windows 11

1. Скопируй `audit_dataset.py` в корень существующего проекта (рядом с `run_ai.py`).
2. Скопируй `tests/test_dataset_audit.py` в свою папку `tests`.
3. Выполни из терминала VS Code:

```powershell
.\.venv\Scripts\python.exe audit_dataset.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Программа ищет JPEG в `data/input/` и **ручные** маски `reports/labels/<имя_снимка>_label.png`, которые сохраняет твой инструмент `label_clouds.py` / `label_more.py`. Снимки и маски не меняет.

## Результаты

- `reports/dataset_audit/labels_audit.csv` — процент облачности по ручной разметке и замечания.
- `reports/dataset_audit/previews/` — фотографии слева и ручные зелёные маски справа.
- В терминале: число размеченных кадров, отсутствие примеров облачности >75%, проблемы масок.

Если хочется вывести все превью (например, после разметки 15 снимков):

```powershell
.\.venv\Scripts\python.exe audit_dataset.py --preview-limit 20
```

## Как размечать

```powershell
.\.venv\Scripts\python.exe label_more.py
```

Закрашивай **всю площадь облаков**, а не отдельные мазки. Не отмечай снег/белые горы/светлые пустыни как облака. На действительно чистом снимке сохрани пустую маску, но проверь её вручную.

Постарайся выбрать **10–12 разных** изображений: над водой, сушей, горными районами, с небольшим, средним и большим количеством облаков. Для конкурсной проверки отсева обязательно нужны снимки с действительно **>75%** облачности. Более разнообразные метки могут потребоваться для хорошего обучения; 10–12 — лишь предварительный набор.

Для честной оценки часть снимков отложим в тестовую выборку. Похожие кадры одной сцены или последовательные кадры нельзя распределять между обучением и тестированием как независимые.

**Не публикуй в GitHub необработанные большие снимки и все размеченные маски без необходимости и проверки условий использования источника.**

## Что отправить в чат

Текст терминала после `audit_dataset.py` и `reports/dataset_audit/labels_audit.csv`. Тогда составим план обучения небольшой модели под твой компьютер. Если имеется очень мало размеченных кадров или все они без облаков, сначала исправим состав выборки.
