# CloudVision AI — этап 2: первый запуск нейросети

Все файлы из этого архива перенеси в **корень уже существующего** проекта
CloudVision AI (рядом с `main.py`). **Не удаляй и не замещай** папки `data`,
`cloudvision`, `tests` и старый `main.py`.

## Windows 11 / VS Code

Открой терминал в корне проекта и выполни команды по очереди:

```powershell
.\.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements-ai.txt
.\.venv\Scripts\python.exe run_ai.py --limit 3
```

При первом запуске веса CLIPSeg (~600 MB) загружаются с Hugging Face.
Это может потребовать некоторого свободного места на диске и подключения
к интернету. Модель запускается на CPU и не требует видеокарты NVIDIA.

Результаты появятся в `reports/cloud_report_preview.csv`, картинки с
красной подсветкой предполагаемых облаков — в `reports/previews/`.

После визуальной проверки первых трёх кадров можно проверить остальные:

```powershell
.\.venv\Scripts\python.exe run_ai.py --all
```

## Важные ограничения

- Нейросеть обучена на снимках Sentinel-2, а не на данных СПУТНИКС.
  Её предсказания нужно сравнивать с реальными облаками на изображении.
- Класс 1 — плотное облако, класс 2 — тонкое облако: оба учитываются.
  Класс 3 — тень от облака: она не учитывается как облачность.
- **Это предварительный просмотр:** исходные фото не удаляются.
  Сначала проверим модель, потом добавим финальную сортировку и удаление
  по условию конкурса (>75%).
- Если предсказания ошибаются, не стоит включать автоудаление.
- Если Python или установка PyTorch выдаёт ошибку, сообщи её целиком.

Источник модели и лицензия: https://huggingface.co/uga-gaim/CLIPSeg-CloudSEN12Plus-FFT
