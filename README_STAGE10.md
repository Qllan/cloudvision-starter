# CloudVision AI — этап 10: первое обучение своей нейросети

**Цель:** провести честный эксперимент на ручных масках СПУТНИКС: обучить небольшую бинарную U-Net (облака / не облака), проверить её на новых снимках и оценить решения по 75%. Нейросеть **не является гарантированно точной**: для её надёжности нужны качественные ручные маски и честная проверка.

## Прежде чем запускать

По `labels_audit.csv` есть 117 разметок, из них 111 `OK`, а 6 `REVIEW`: 3 почти полностью белые маски и 3 пустые. ВНИМАТЕЛЬНО проверь все 6 визуально. Скрипт **по умолчанию исключает `REVIEW`** из обучения. Это не ошибка, и менять корректную разметку ради автоматической проверки не нужно.

123 фото — 117 размечено, 6 нет. Четыре фото имеют размер 3280 × 2564; скрипт учитывает пропорции.

## Установка файлов

Распакуй архив и **скопируй** в корень существующего проекта (там, где `main.py`, `run_ai.py`, `audit_dataset.py`):

- `split_dataset.py`
- `train_cloudvision.py`
- файл из `tests/test_training_stage.py` в свою папку `tests/`

**Не заменяй** другие программы и не удаляй ни одного изображения.

## Шаг 1. Повторный аудит, если исправлял разметку

```powershell
.\.venv\Scripts\python.exe audit_dataset.py
```

## Шаг 2. Разделить изображения на группы

```powershell
.\.venv\Scripts\python.exe split_dataset.py
```

Создаст `reports/training/dataset_split.csv` со столбцом `split`: `train`, `val`, `test`. Снимки **одного дня с одинаковой камерой** всегда находятся в одной группе: похожие последовательные кадры не попадут одновременно в обучение и тест. Разделение детерминированное (seed=42). Для независимости используйте отдельные сцены; даже это не гарантирует полной независимости при повторных съёмках одного района в другие даты.

## Шаг 3. Запустить обучение на Windows 11 (CPU)

```powershell
.\.venv\Scripts\python.exe train_cloudvision.py --epochs 10
```

`torch`, `numpy` и `Pillow` уже установлены на предыдущих этапах. Если Python напишет `No module named torch`, выполни установку из инструкции этапа 3. Вариант для более слабого ПК:

```powershell
.\.venv\Scripts\python.exe train_cloudvision.py --epochs 6 --size 128 --batch-size 2
```

Учится небольшая **U-Net**, созданная нами и инициализированная случайно: это не дообучение CLIPSeg, а новая экспериментальная модель. На входе используется RGB-фото, целиком уменьшенное с сохранением пропорций. Выход — пиксельная маска «облако / не облако». Считаются и тонкие, и плотные облака (если они есть в ручной разметке). Тени как отдельный класс пока не выделяются. Первая версия может ошибаться, особенно с мелкими облаками.

### Что создастся

- `models/cloudvision_unet.pt` — веса лучшей по проверочной группе версии модели.
- `reports/training/training_history.csv` — изменение ошибки по эпохам.
- `reports/training/test_predictions.csv` — проценты облачности на **отдельной тестовой группе**, MAE, IoU и совпадение решения «сохранить / отсеять».
- `reports/training/test_previews/` — сравнение оригинала, ручной маски (зелёная) и результата ИИ (красная).

Изначальные фотографии и ручные маски **не меняются и не удаляются**. Модель автоматически не подключается к `process_satellite_images.py`: до этого шага сначала нужно измерить качество.

## Почему такой эксперимент полезен для конкурса

1. Мы создали собственную компактную нейросеть на PyTorch.
2. Обучаем на размеченных кадрах СПУТНИКС, а не только на снимках Sentinel-2.
3. Разделяем похожие кадры на уровне групп, чтобы не завысить метрики.
4. Фиксируем выбор лучшей эпохи по **validation**, а тест не используем для подбора параметров.
5. Измеряем процент облачности, IoU и ошибки решения около 75%.

**Не утверждай, что обучение автоматически делает модель лучше**. Сравни MAE и IoU новой модели с CLIPSeg только при одинаковом независимом тестовом наборе. Если будешь менять архитектуру по результатам теста, потребуется новый независимый набор для финальной оценки.
