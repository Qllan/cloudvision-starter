# CloudVision AI — Этап 5: эксперимент с фрагментами

## Что делает скрипт

- Берёт только те снимки, для которых уже есть ручная разметка в `reports/labels/`.
- Обрабатывает каждый снимок **четырьмя перекрывающимися частями**, используя **ту же CLIPSeg**, что использовалась на предыдущем этапе.
- Усредняет оценки модели в местах перекрытия, создаёт новую маску и сравнивает с твоей ручной разметкой.
- Если старые маски находятся в `reports/masks/`, выводит показатели «было / стало».
- **Не удаляет и не перемещает оригинальные снимки**, не изменяет предыдущие маски и ручные разметки.

## Инструкция для Windows 11

1. Распакуй архив. Скопируй `experiment_tiling.py` в **корень существующего проекта**, рядом с `run_ai.py`. Файл `README_STAGE5.md` — инструкция; `tests/test_tiling.py` можно добавить в папку `tests`.
2. Убедись, что в `reports/labels/` остались три твои ручные разметки и в `data/input/` находятся соответствующие JPG.
3. Открой терминал VS Code из папки проекта и выполни:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe experiment_tiling.py --limit 1
```

Сначала проверь, что всё работает на **одном** снимке. Затем:

```powershell
.\.venv\Scripts\python.exe experiment_tiling.py --limit 3
```

## Где результаты

- `reports/tiling_experiment/comparison_metrics.csv` — таблица со значениями облачности, ошибки и IoU для двух подходов.
- `reports/tiling_experiment/comparisons/` — цветные изображения с ошибками нового подхода.
- `reports/tiling_experiment/masks/` — новые маски классов от 0 до 3.

Цвета: зелёный — правильно найденные облака; красный — ложные; синий — пропущенные.

## Как оценивать

Сравни IoU и абсолютную ошибку в процентах на **одних и тех же размеченных снимках**. Больший IoU и меньшая ошибка обычно лучше. Если результаты ухудшились, не нужно использовать новый подход только потому, что он сложнее.

**Внимание:** грубые ручные метки сильно влияют на метрики. Если разметка состоит из отдельных линий, а не полностью закрашенных облаков, сначала исправь разметку в `label_clouds.py`. Не надо автоматически доверять количественным оценкам по трём снимкам.

Для конкурсного правила: снимок подлежит удалению **только при облачности строго выше 75%**. До проверки модели автоматическое удаление выключено.
