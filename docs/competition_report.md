# CloudVision AI — итоговый технический отчёт для СПУТНИКС

Отчёт создаётся офлайн из **уже завершённых** независимых проверок v3/v4
(5 снимков) и v4/v5 (24 снимка), 10 VAL, 30 AI-assisted пилотных масок
и сохранённой истории обучения v5. Никакого инференса, переобучения,
доступа к интернету или изменения исходных JPEG/PNG/checkpoint не требуется.

## Создание

В Windows PowerShell из корня репозитория после обновления ветки:

    git pull --ff-only origin feature/gpu-batch-resume
    .\.venv\Scripts\python.exe build_competition_report.py
    Start-Process .\reports\competition_final\cloudvision_report.html

Скрипт использует только стандартную библиотеку Python. Готовый файл
\`reports/competition_final/cloudvision_report.html\` **самодостаточен**:
все стили, SVG-график и (при наличии) один пример пилотного превью
включены непосредственно в HTML. При необходимости можно в браузере
выбрать **Печать → Сохранить как PDF**, без установки отдельного модуля.

По умолчанию читаются:

- \`reports/final_test_v4/summary.csv\` и \`per_image.csv\` — старый TEST
  (сравнение v3 и v4, всего 5 кадров);
- \`reports/v5/final_holdout/summary.csv\` и \`per_image.csv\` — новый TEST
  (сравнение v4 и v5, всего 24 кадра);
- \`reports/training_v5/model_comparison.csv\` — контрольная VAL (10 кадров);
- \`reports/training_v5/training_history.csv\` — эпохи обучения v5;
- \`reports/competition_pilot_v4/operator_review/operator_review.csv\` —
  30 кадров с ручной коррекцией масок;
- \`reports/competition_pilot_v4/operator_review/previews/\` — необязательная
  иллюстрация типичной ошибки маски на поверхности.

Программа проверяет состав моделей и совпадение эталонов у двух моделей,
число кадров, согласованность MAE/IoU и количество ложных или
пропущенных отсевов. Если CSV неполный или изменён, генерация
останавливается. Если выходной HTML существует, он **не перезаписывается**:
чтобы создать новую редакцию, используй другой \`--out\`.

## Что важно сказать жюри

- Правило проекта — **ОТСЕЯТЬ только при облачности строго выше 75%**.
  Ровно 75% означает «СОХРАНИТЬ».
- На независимом TEST из 24 кадров v4 получила MAE 16.63 п.п.,
  v5 16.43 п.п.; обе правильно приняли 23/24 решений, обе сделали
  по одному ложному отсеву. Средние IoU: v4 0.48290, v5 0.48222.
- **Ни один из 24 эталонов не превышал 75% облачности**, поэтому
  способность пропускать/обнаруживать действительно сильно облачные
  кадры на этом TEST измерить нельзя. Даже стратегия «сохранить всё»
  дала бы здесь 24/24 верных решений.
- 30 пилотных масок создавались с AI-подсказками; эти результаты не
  являются независимым TEST v5. В пилоте v4 пропустила три снимка,
  у которых ручная доля облаков превышала 75%.
- Случаи ложных масок на рельефе и море — основная техническая
  проблема. Исходники нельзя удалять автоматически: оператор
  должен проверить предлагаемое решение.

## Безопасность и воспроизводимость

Не включай \`data/\`, \`models/\`, \`reports/\` или локальные JPEG/PNG/маски
в GitHub. В репозитории хранятся **только скрипт, тесты и инструкции**.
PR остаётся draft; не объединяй его с \`main\` без отдельного решения.

## Следующая самостоятельная проверка

Для измерения эффективности отсева нужны *новые* кадры с эталонной
облачностью >75%, вручную размеченные без AI-подсказок.
Такой специально собранный набор необходимо обозначать как
«целевая сложная выборка», а не выдавать за случайную репрезентативную
проверку. Нельзя настраивать уже замороженные v4/v5 на ранее увиденном TEST.
