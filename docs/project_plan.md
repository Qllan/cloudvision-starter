# План проекта: строго по кейсу «СПУТНИКС»

## Требования

- Вход: изображения со спутника.
- ИИ: получить маску облачности (облако / не облако) для каждого пикселя.
- Вычисление: `облачность = число пикселей, отнесённых ИИ к облакам / число всех анализируемых пикселей × 100%`.
- Правило: `облачность > 75%` → отклонить и удалить; `<= 75%` → сохранить.
- Отчёт оператору: имя сохранённого файла, процент облачности, имя удалённого файла.
- Результат: презентация `.pptx` с описанием алгоритма, этапами и демонстрацией.

## Этапы

1. ✅ Среда, проверка открытия изображений и тест точного порога 75%.
2. Подготовить доступные изображения СПУТНИКС; оценить формат и наличие размеченных масок.
3. Подобрать лёгкую предобученную нейросеть для сегментации облаков либо обучить небольшую модель на размеченных данных.
4. Рассчитать долю облаков из маски и визуализировать её поверх снимка.
5. Сделать безопасный режим проверки с перемещением отклонённых снимков в `data/rejected`.
6. Добавить подтверждённый режим удаления и отчёт CSV/TXT (без потери тестовых исходников).
7. Проверить точность на отложенных снимках; отдельно проверить ошибки вокруг 75%.
8. Подготовить `.pptx`, скриншоты/видео демонстрации, README с воспроизводимым запуском.

## Важные технические решения

- Нельзя считать цвет «белый» доказательством облака: снег, песок и блики похожи.
- Использовать настоящую модель машинного обучения; простые цветовые пороги допустимы только как сравнительный базовый метод.
- Не отправлять большие снимки, контрольные данные, ключи или личную информацию в GitHub.
- Пока модель не готова, не выводить выдуманные значения облачности.
