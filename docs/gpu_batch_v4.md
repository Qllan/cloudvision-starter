# CloudVision AI v4 — массовый анализ снимков (preview-only)

## Цель

Обработать большой набор спутниковых снимков СПУТНИКС, не потерять прогресс,
получить первичные маски от обученной U-Net Policy и затем исправить их вручную.
В этой версии **нет режима удаления и перемещения изображений**.

## Подготовка

- Windows 11, Python и зависимости текущего проекта.
- PyTorch с CUDA — проверка:
      .\.venv\Scripts\python.exe -c "import torch; print(torch.cuda.is_available())"
- Локальный файл моделей: models/cloudvision_unet_v3_policy.pt
- Изображения могут лежать в подпапках data/new_raw.
- Запускать программу из корня GitHub-репозитория.

Для первого запуска:

    .\.venv\Scripts\python.exe run_batch_v4.py --input data/new_raw --out reports/batch_v4_new --device cuda --limit 5

Для продолжения:

    .\.venv\Scripts\python.exe run_batch_v4.py --input data/new_raw --out reports/batch_v4_new --device cuda

Можно использовать --device auto (CUDA при наличии, иначе CPU). Не запускай
на всём наборе до проверки первых пяти результатов.

## Что происходит

1. Рекурсивный поиск JPG, JPEG, PNG, TIFF, WEBP, без перехода по симлинкам.
2. Загрузка U-Net Policy один раз; обработка по одному файлу.
3. Маска 0/255 в полном исходном разрешении, в той же структуре подпапок.
4. SQLite progress.sqlite3 записывается после каждого успешного кадра.
5. При повторном запуске готовые кадры пропускаются, если размер файла, время
   изменения и SHA-256 модели не менялись и маска существует.
6. CSV operator_preview.csv содержит проценты и решения по порогу 75%.
   В нём указывается, что действия — только предпросмотр.
7. Ошибочные изображения не прерывают обработку остальных: список неудач
   хранится в таблице failures базы SQLite.

Уникальные относительные пути сохраняются, поэтому одинаковые имена в разных
подпапках не конфликтуют. Разные датасеты должны использовать разные --out;
программа откажется смешивать их в одной папке.

## Исправление масок

    .\.venv\Scripts\python.exe label_with_ai_fast.py --input data/new_raw --ai-masks reports/batch_v4_new/masks --out data/verified_new

Редактор повторяет подпапки исходного набора. Исправленные маски не заменяют
AI-предсказания и прежние ручные разметки. Если предсказание не найдено,
редактор явно укажет на отсутствие маски.

## Ограничения и честная оценка

- Нейросеть экспериментальная. Расчёт по ней может значительно расходиться с
  фактической облачностью.
- Обрабатывается уменьшенная до входа сети версия исходного кадра, затем
  маска увеличивается до исходного разрешения. Малые облака могут теряться.
- Повторные, похожие по сцене кадры не должны попадать одновременно в обучение
  и независимое тестирование.
- Не используй AI-предсказания как бесспорную разметку для обучения.
- При недостоверных масках требуется проверка человеком.
- При запуске из Windows другое имя диска / папки меняет идентификатор
  датасета для кэша: используй отдельный --out.
- Для очень больших наборов может потребоваться больше места под полные PNG-маски.
