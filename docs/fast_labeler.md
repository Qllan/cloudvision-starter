# CloudVision AI — быстрый редактор масок

Версия для Windows 11, без Matplotlib. `Tkinter` есть в стандартном Python для Windows; требуется уже установленная библиотека Pillow.

## Установка
1. Положите `label_with_ai_fast.py` рядом с `run_competition_demo.py` в папке своего проекта.
2. Убедитесь, что результаты первого полного прохода находятся в `reports/competition_demo/masks`. В этапе 14 маски называются `ИМЯ_СНИМКА_policy_mask.png`.
3. Откройте терминал VS Code в корне проекта и запустите:

```powershell
.\.venv\Scripts\python.exe label_with_ai_fast.py
```

Чтобы начать с определённого изображения:

```powershell
.\.venv\Scripts\python.exe label_with_ai_fast.py --start 2025-09-18
```

## Работа
- ЛКМ — добавить облака; ПКМ — убрать облака.
- S — сохранить; N / B — следующий / предыдущий; O — показать/скрыть маску.
- R — сбросить маску к исходному предсказанию ИИ (с подтверждением).
- + / − — изменить кисть; Q — выход.
- Зелёный слой — текущая исправляемая маска; при удалении во время мазка появляется красный временный след, который исчезнет после отпускания мыши.

## Сохранение
- Исправления: `data/manual_masks_ai/<имя_снимка>.png` — **полный размер** и пиксели **0/255**.
- Журнал: `reports/label_assisted/label_log.csv`.
- Оригиналы в `data/input`, предсказания в `reports/competition_demo/masks` и старые разметки не меняются.
- Если уже есть исправленная маска, она загрузится для продолжения. Перед переходом программа спросит о несохранённых изменениях.

## Почему быстрее
Программа показывает один масштабированный снимок; перо рисует быстрой векторной линией на Canvas. Полная маска обновляется **один раз в конце мазка**, а на диск записывается только при сохранении.

## Важно
- Облака — классы 1 и 2 в многоуровневой маске; класс 3 (тени) не считается облаками.
- Для очень тонких облаков при масштабе экрана может не хватить точности; их границы следует перепроверять по оригиналу.
- Автоматическое удаление не используется.
