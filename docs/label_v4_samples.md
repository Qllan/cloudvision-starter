# CloudVision AI v4 — отбор и разметка новых кадров СПУТНИКС

Цель: улучшить сегментацию облачности после проверки пяти фотографий,
на которых U-Net v3 ошибочно принимала сушу и море за облака.
Сначала размечаем небольшой разнообразный набор из 4207 кадров.

## 1. Сохранить исходный результат

Исходные пять масок и report оставляем в reports/batch_v4_new.
Они исследовательские; **не использовать их для отчёта по новому слепому тесту**.

Не перемещать, не удалять и не загружать исходные снимки в GitHub.
Папку extra распаковывать пока не нужно.

## 2. Составить неизменяемую выборку из 50 снимков

    .\.venv\Scripts\python.exe select_v4_samples.py --input data/new_raw --count 50 --out reports/selection_v4/selection.csv

Скрипт обходит файлы и создаёт небольшие RGB-превью для оценки разнообразия
(цвет, яркость, текстура), но **не использует предсказания нейросети**.
Кадры одной даты/камеры группируются вместе. CSV содержит relative_path,
scene_group, split (train / val / test).

Если есть прежний reports/batch_v4_new/operator_preview.csv, уже просмотренные
кадры исключаются, чтобы тестовая группа не содержала знакомые изображения.
CSV **не перезаписывается**, чтобы выборка оставалась зафиксированной.
Не запускай селектор второй раз с другим seed после просмотра результатов.

Список автоматически делится примерно на 35 train, 10 val и 5 test,
но реальные пропорции могут немного измениться из-за групп кадров.

## 3. Создать маски нейросети для train и val, НЕ test

    .\.venv\Scripts\python.exe run_batch_v4.py --input data/new_raw --out reports/batch_v4_selected --manifest reports/selection_v4/selection.csv --splits train,val --device cuda

Программа создаёт маски 0/255 только для выбранных обучающих и валидационных
снимков. Прогресс хранится в SQLite; при повторном запуске готовые снимки
пропускаются. Ничего не удаляется.

## 4. Исправить маски в быстром редакторе

    .\.venv\Scripts\python.exe label_with_ai_fast.py --input data/new_raw --ai-masks reports/batch_v4_selected/masks --out data/verified_v4 --manifest reports/selection_v4/selection.csv --splits train,val

На каждом кадре:
- проверь зелёную маску по исходному RGB;
- ЛКМ добавляет облако, ПКМ убирает ложное облако;
- S сохраняет исправленную маску в полном разрешении;
- N открывает следующий кадр, B предыдущий.

Не считай AI-маску «проверенной», пока сам не просмотрел и не сохранил её.
Учитывай также тонкие облака, не закрашивай облачные тени.
Исходные изображения и предсказания AI сохраняются без изменений.

## 5. Дальше — обновление U-Net

После окончания разметки объединяем старые проверенные данные с новыми
train/val. Важно сохранить разбиение по группам и проверить дубликаты между
старым и новым датасетом. Независимый TEST не используется ни в выборе эпохи,
ни в подборе порогов и гиперпараметров.

Для TEST сначала вручную создаём эталонные маски **без подсказки модели**,
затем единожды оцениваем уже зафиксированную версию сети. Считаем MAE процента
облачности, IoU и решения относительно порога строго >75%.

## Ограничения выборки

Стратификация по RGB-признакам помогает разнообразию, но **не гарантирует**
идеального покрытия плотной/тонкой облачности или отсутствие почти одинаковых
снимков разных дат. Перед итоговой оценкой потребуется проверка близких кадров.
Нельзя считать 50 кадров статистически достаточными для доказательства
высокой точности. Задача — улучшить модель и подготовить честную проверку.
