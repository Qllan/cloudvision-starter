# CloudVision AI — этап 4: визуальная проверка ошибок

Это **диагностика**, а не новая модель и не доказательство её точности.

## Windows 11, в уже существующем репозитории

1. Скопируй `compare_cloud_masks.py` в корневую папку CloudVision AI, рядом с `run_ai.py`.
2. Убедись, что существуют папки `data/input`, `reports/masks`, `reports/labels`.
3. Запусти терминал VS Code в корневой папке проекта:

```powershell
.\.venv\Scripts\python.exe compare_cloud_masks.py
```

4. Открой созданные изображения в папке `reports/comparisons`.

Каждое изображение сравнения содержит две части:
- слева — исходный спутниковый снимок;
- справа — исходный снимок с подсветкой ошибок.

**Цвета:**
- зеленый: модель и человек согласны, что здесь облако;
- красный: модель считает пиксель облаком, ручная разметка нет;
- синий: человек отметил облако, модель его пропустила;
- без подсветки: обе маски считают участок чистым.

## Если ручная облачность равна 0%

Убедись, что на исходном снимке действительно нет облаков. Если ошибка в разметке:

```powershell
.\.venv\Scripts\python.exe label_clouds.py
.\.venv\Scripts\python.exe evaluate_ai.py
.\.venv\Scripts\python.exe compare_cloud_masks.py
```

Открой нужный снимок, правильно закрась облака и сохрани разметку.

## Что не следует делать

Не включай автоматическое удаление исходников. Три снимка — слишком мало, чтобы доказать точность классификации на пороге 75%. Следующий этап — получить дополнительные разметки на разных типах поверхности, включая сильно облачные снимки, и сравнить методы обработки.

Для публичного GitHub пока коммить только код. Папки `data` и `reports` должны оставаться локальными, пока не проверены условия распространения снимков.
