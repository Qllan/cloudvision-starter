# CloudVision AI — этап 13: отложенная оценка Area и Policy

Этот этап **не обучает** модель и **не удаляет/копирует** исходные снимки. Он только читает две готовые модели, фотографии и маски тестовой группы.

## Зачем

На 17 валидационных снимках Policy верно отсеяла 2/2 сильно облачных, но хуже оценивала процент облачности (MAE 18,31 п.п. против 11,16 п.п. у Area). Двух сильно облачных примеров недостаточно для вывода о надёжности.

Мы заранее фиксируем назначение моделей: **Policy — кандидат для правила 75%, Area — для точности процента**. Результаты TEST не должны менять этот выбор. Если обнаружатся ошибки, нужен **новый независимый набор** для следующей итерации и отдельная финальная проверка.

*Примечание:* эти 16 TEST-кадров уже использовались при сравнении первой версии U-Net, поэтому **тестовая выборка не полностью «невиданная» в истории проекта**. Не называй её окончательно независимым доказательством надёжности.

## Установка на Windows 11

Из архива добавь `evaluate_v3_test.py` в корень проекта рядом с `train_cloudvision.py` и `train_cloudvision_v2.py`. Файл `tests/test_stage13.py` скопируй в папку `tests`.

Открой терминал VS Code в корне проекта:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe evaluate_v3_test.py
```

Скрипт проверит существующее разбиение, откроет TEST один раз, рассчитает метрики обеих контрольных точек и сохранит:

- `reports/test_v3/test_comparison.csv` — общее сравнение на TEST;
- `reports/test_v3/test_predictions_area.csv` и `test_predictions_policy.csv` — результаты по снимкам;
- `reports/test_v3/previews_area` и `previews_policy` — шесть визуализаций каждой модели;
- `reports/test_v3/test_summary.json` — тот же итог в JSON.

**Не включай `--mode delete`**. На данном этапе сортировка не запускается. Всё ещё нужно проверить много новых кадров, особенно вокруг 75%, прежде чем разрешать удаление.

## Что прислать

`test_comparison.csv` и текст терминала. После этого можно собирать демонстрационное приложение, которое показывает процент, решение и причины, не удаляя оригиналы. Для честной итоговой оценки рекомендуется свежая тестовая выборка, не использованная ни при одном обучении или настройке.
