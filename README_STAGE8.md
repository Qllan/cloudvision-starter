# CloudVision AI — этап 8: реальная сортировка и отчёт оператора

Проведён эксперимент: текущая модель всё ещё ошибается на снимках СПУТНИКС. Поэтому **не включай удаление оригиналов**, пока не проверишь качество на независимой выборке.

Программа ниже реализует **функциональные требования конкурса**: расчёт процента облачности по маске ИИ, порог 75%, имена сохранённых и удалённых файлов, CSV-отчёт. Точность определения облаков — отдельная задача, пока НЕ решённая.

## Установка

Скопируй `process_satellite_images.py` в корень старого проекта рядом с `run_ai.py`. Файл `tests/test_processing.py` положи в `tests`. В коде предыдущих этапов ничего заменять не надо. Python, Pillow, NumPy, torch и transformers уже установлены.

**Важно:** берутся индексные PNG из `reports/tiling_experiment/masks/`, а не цветные JPG из `previews`. Классы: 0=чисто, 1=плотные облака, 2=тонкие облака, 3=тень. В облачность входят классы 1 и 2.

## Безопасная первая проверка на 3 снимках

В терминале VS Code из корня проекта:

```powershell
.\.venv\Scripts\python.exe process_satellite_images.py --limit 3
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

По умолчанию это **только предварительный просмотр**: изображений не копирует, не перемещает и не удаляет. Создаёт CSV:

- `reports/processing/planned_actions.csv` — план решений;
- `reports/processing/processing_report.csv` — фактически выполненные действия (в preview — только предварительные решения).

Если в первой тройке нет масок, программа пропустит их и объяснит почему. Это не ошибка. Добавь `--infer-missing` — нейросеть CLIPSeg создаст их на CPU (используется твой исправленный `experiment_tiling.py`).

```powershell
.\.venv\Scripts\python.exe process_satellite_images.py --limit 3 --infer-missing
```

### Обработка всех изображений

```powershell
.\.venv\Scripts\python.exe process_satellite_images.py --infer-missing
```

Модель может работать долго на CPU. Маски сохраняются и при повторных запусках используются повторно; заново считать их не нужно.

### Создать папку с сохранёнными снимками

```powershell
.\.venv\Scripts\python.exe process_satellite_images.py --mode copy
```

В `data/accepted/` будут скопированы снимки с прогнозом облачности **≤ 75%**. Оригиналы останутся в `data/input/`. Повторное копирование в ту же папку запрещено, чтобы избежать перезаписи.

### Демонстрация настоящего удаления — ТОЛЬКО НА КОПИЯХ

Для проверки правила конкурса скопируй несколько снимков (не перемещай!) из `data/input/` в новую папку `data/work_input/`. Если их маски готовы, можно выполнить:

```powershell
.\.venv\Scripts\python.exe process_satellite_images.py --input data/work_input --mode preview
```

Если предварительный отчёт выглядит ожидаемо, явное удаление только из `data/work_input/`:

```powershell
.\.venv\Scripts\python.exe process_satellite_images.py --input data/work_input --mode delete --confirm-delete
```

Программа удалит из рабочей папки копии снимков с прогнозом **строго >75%**, сохранит остальные в `data/accepted/`, создаст CSV с названиями сохранённых и удалённых файлов. Удаление из `data/input` заблокировано.

> Поскольку текущая нейросеть ещё недостаточно точна, не используем `--mode delete` для исходных данных.

## Важно для точности

- Порог ровно 75% — **сохранить**; 75.001% — к удалению.
- Тени облаков не считаются облаками.
- Программа не создаёт облачные маски из воздуха: без готовой маски и без `--infer-missing` файл не обрабатывается.
- Модель пока не готова к надёжной сортировке: проверь больше разнообразных вручную размеченных снимков, включая >75%, и сравни по IoU, ошибке процента и правильности решения порога.
- Результаты экспериментов, изображения и маски лучше исключать из GitHub. Проверь `.gitignore`.

Если ты ранее запускал `--mode copy`, для демонстрации удаления используй другую папку для сохранённых копий, чтобы не столкнуться с уже существующими файлами:

```powershell
.\.venv\Scripts\python.exe process_satellite_images.py --input data/work_input --mode delete --confirm-delete --accepted data/demo_accepted
```

При демонстрации на твоих трёх снимках пока не будет реального удаления, если все прогнозы не превышают 75%. Проверка этого случая есть в тестах с искусственной маской 100%: это проверка программной логики, **не** точности нейросети.
