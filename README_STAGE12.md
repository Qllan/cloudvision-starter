# CloudVision AI — этап 12: две лучшие модели, один эксперимент

## Что мы выяснили

На эпохе 28 предыдущая модель имела низкую среднюю ошибку облачности, но не отклонила ни одного из двух сильно облачных проверочных снимков. На эпохе 30 точность решений по порогу была 100% на тех же 17 проверочных изображениях, но ошибку процента программа показала выше.

**Нам нужны обе версии, чтобы сравнить их**, но предыдущий скрипт сохранял только лучшую по MAE. Этап 12 повторно обучает U-Net и сохраняет сразу две контрольные точки. Результаты нового запуска могут немного отличаться из-за случайности вычислений.

## Установка

1. Скопируй `train_cloudvision_v3.py` в папку проекта рядом с `train_cloudvision.py` и `train_cloudvision_v2.py`.
2. Скопируй `tests/test_stage12.py` в папку `tests`.
3. Открой терминал VS Code в корне проекта на Windows 11.

Проверка тестов:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Обучение на CPU:

```powershell
.\.venv\Scripts\python.exe train_cloudvision_v3.py --epochs 30
```

При ограниченных ресурсах **только для отдельного эксперимента**:

```powershell
.\.venv\Scripts\python.exe train_cloudvision_v3.py --epochs 30 --size 128 --batch-size 2
```

Второй вариант не сопоставим напрямую с прежним 192×192 — он использует другое разрешение. Выбери один режим и не смешивай результаты.

## Результаты

- `models/cloudvision_unet_v3_area.pt` — модель с минимальной ошибкой процента облачности на VAL.
- `models/cloudvision_unet_v3_policy.pt` — модель с максимальной сбалансированной точностью решений по порогу 75% на VAL.
- `reports/training_v3/model_comparison.csv` — сравнение моделей.
- `reports/training_v3/training_history.csv` — история обучения.
- `reports/training_v3/validation_predictions_area.csv` и `validation_predictions_policy.csv` — прогнозы на валидации.
- `reports/training_v3/previews_area/` и `previews_policy/` — иллюстрации предсказаний.

Для порога строго **выше** 75% = `REJECT`; ровно 75% = `KEEP`.

**Важно**: 17 изображений и 2 примера высокой облачности — слишком мало для уверенного вывода. Даже 100% на VAL не означает 100% в работе. Не использовать эти модели для автоматического удаления исходных фото. Папка TEST этим скриптом не открывается.
